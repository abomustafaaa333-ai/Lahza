# الحذف اليومي التلقائي لطلبات لحظة

تشغّل الخدمة الرئيسية للتطبيق بشكل طبيعي. ولحذف الطلبات التي مضى على إنشائها أكثر من سبعة أيام حتى عندما لا يفتح أحد لوحة التحكم، أنشئ خدمة ثانية من المستودع نفسه داخل مشروع Railway.

| الإعداد | القيمة |
|---|---|
| المستودع | `abomustafaaa333-ai/Lahza` |
| أمر البدء | `pnpm cleanup:orders` |
| الجدول اليومي | `15 0 * * *` |
| المنطقة الزمنية | UTC، أي 03:15 صباحاً بتوقيت سوريا GMT+3 |
| المتغيرات | انسخ متغيرات بيئة الخدمة الرئيسية، وبالأخص `DATABASE_URL` |

تبدأ الخدمة، تحذف طلبات التوصيل وسيارات الأجرة وطلبات جرابلس الأقدم من سبعة أيام، ثم تنهي عملها. يجب ألا تُستبدل الخدمة الرئيسية بهذه الخدمة؛ بل تضاف خدمة ثانية مستقلة.
